# 流程与校准

这份文档记录「要让结论可信，哪些条件必须先钉死」。全是我们自己踩过的坑，按开跑顺序排列。

## 1 先钉死被测对象

| 项 | 做法 |
|---|---|
| DSH 版本 | `config.dsh_version_pin` 写死；`doctor` 会比对，不一致直接拒绝开跑 |
| 模型版本 | `model_version_expected` 与代理侧观察到的 model 字段比对 |
| 工具面 | 每臂一个覆盖层，`expect` 逐条断言（规则数 / PTC 开关 / 关键行参数） |
| 预热 | 每臂第一遍不要算进结论（缓存与进程冷启动），或统一先跑 `smoke` |

**坑 1**：某些 DSH 版本里 `tools.config.mode: ptc` 已经不生效（启动即 `ValidationError`）。判断「是不是 PTC 工具面」只能看 `tool-executor-native / tool-executor-ptc` 的 `disabled`。

**坑 2**：覆盖层写错一行 id，DSH 会静默忽略（甚至整层不生效），两臂跑出来一模一样还不报错。所以每次建会话前都要读回合成配置做金丝雀断言。

**坑 3**：预设的差异一半在参数上（压缩阈值、结果裁剪、搜索抽样），只对齐「规则文本」是不够的——那会得到「规则一致、参数不一致」的假对照。

## 2 记账：不要相信面板

- 每个臂单独一个记账代理端口（`arms.<臂>.proxy_port`），代理逐次记录 `cache_hit / cache_miss / output` 与耗时。
- 用运行期生成的 route 覆盖层把模型 `baseURL` 指过去；命令行覆盖层优先级高于网页保存的地址，因此不会串。
- 费用一律**按 token 重算**，不取面板里的金额；面板金额受时段折扣与缓存口径影响，跨臂不可比。
- 半价时段：若某臂恰好跑在折扣时段，钱会凭空少一半。统一按高峰价折算即可消除。

## 3 并发与槽

- `max_parallel` 是**全局**上限；`stages.*.slots_per_arm` 是每臂的并行槽。
- 槽多不等于快：同机多槽会抢磁盘和网络，**工具耗时会被放大**（实测同一臂并发翻三倍后，单次工具耗时接近翻倍）。报告墙钟必须说明并发量级，否则两臂不可比。
- `slot_shards` 把每臂的槽再分片，避免一个臂同时打开过多文件句柄。
- 结论以 token/费用为主线（与并发无关），墙钟只作辅证。

## 4 供应商抗故障

- `provider_retry`：503/429 时运行内重试（30/90/180 秒退避，每次换干净工作目录），避免一次抖动毁掉整个 run。
- `provider_health_probes` / `provider_probe_s`：开跑前连续探测通过才放行。
- `provider_fail_threshold` + `adaptive_slots`：连续失败即熔断暂停；最近 10 分钟错误率过高时自动把并发减半。
- 事故恢复：`retry --status provider_error,exit1` 清掉失败状态后续跑，已完成的不重跑。

## 5 判分与重跑

- `grading: after`：全部跑完再判。判分器崩溃或改判分逻辑都不会白跑采集。
- `grade --regrade --prefix <前缀>`：只重评某类题，旧结果自动备份。
- `forget <前缀>`：题面或判分标准发现有错时把该批作废（不删数据，只标无效）。
- 判分器改动后先跑 `selftest`，再 `grade --regrade`。

## 6 开跑前 checklist

```
[ ] doctor 全绿：python 依赖、dsh 可执行、版本 pin、端口空闲、磁盘 >= 20 GB
[ ] config 里只有要比的两臂，端口不冲突；expect 断言写得能被打回（故意改错一层试试）
[ ] setup 建好 profile，runs/_setup/profiles.json 每臂一个中性名字
[ ] smoke 两题跑通，代理日志里能看到 token 记账
[ ] leakcheck 通过（题目目录里没有答案明文、没有题源字样）
[ ] 记录开跑环境：DSH 版本、模型版本、并发、时段
[ ] 跑完先 interim 看区间，够用就别再跑（省钱）
```

## 7 报告口径

- 主表：每臂 正确率 / 95% 区间 / 总 token / 三类 token 拆分 / 缓存命中率 / 等价费用 / 每次答对成本。
- 相对量：费用比（含区间）与正确率差（含区间）必须成对出现，单看一边会误导。
- 墙钟：只在同一并发量级下横比，并注明是否排除排队等待。
